# Text fonts

The 52 built-in fonts of the Text thing (55 files: Poppins comes as one file a weight). They ship as a
`fonts\` folder beside `ball-studio.exe` and `bpe-render-next.exe` (the program looks in the `BPE_FONTS`
folder, then `fonts\` beside the exe, then this folder). Without them a Text draws in IBM Plex Sans
SemiBold, which is built into the program.

All come from Google Fonts (`https://github.com/google/fonts`). Each family's licence is in `licences/`:
the SIL Open Font Licence 1.1 for all but Chewy, Luckiest Guy, Permanent Marker and Satisfy, which are
Apache 2.0. Both allow the fonts to be shipped with the program.
