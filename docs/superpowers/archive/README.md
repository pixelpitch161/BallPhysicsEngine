# Archive: Version 1 documents

Everything here was written before the 2026-11-03 strip-down, for the old engine (**Version 1**, kept on the
`version-1` branch). Most of what these specs, plans and reports describe was removed: the old crates, node graphs,
the canvas and paint marks, the old sound and chord system, the Explore and Batch windows and many thing kinds.
A few ideas were rebuilt later in a different form.

A few still describe features that survived in a similar form: blend modes (`plans/2026-10-30-colour-blending.md`),
palettes and the grade (`plans/2026-10-30-colour-palettes-grade.md`) and the scene settings
(`specs/2026-10-31-scene-settings-design.md`). Check the code before relying on them.

Otherwise they are history, not instructions. For how the program works now, read `CLAUDE.md` and the notes in `docs/notes/`;
for current designs, `docs/superpowers/specs/` and `docs/superpowers/plans/`.
