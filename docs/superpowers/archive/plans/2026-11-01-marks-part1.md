# Marks Layer Part 1 (Paint Canvas) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Paint canvas thing that balls paint trails onto and that hit splats stamp onto, kept exactly by the simulation and drawn sharp by the graphics card with the Flat style.

**Architecture:** The canvas sim (bpe-kit) stamps marks into a coarse copy-on-write grid and logs each mark, with its final colour, into a new `Log.marks` table that is not hashed. The graphics card replays those marks into two textures per canvas inside the existing `FlowLayers` driver, which already steps a private world with checkpoints, so seeking and exports match. A canvas draw part pushes a `CanvasLayer` that the renderer composites in its layer with the Flat style.

**Tech Stack:** Rust, wgpu/WGSL, existing bpe-core settings derive, bpe-runtime World/Log, bpe-gfx FlowLayers, egui editor.

**Spec:** `docs/superpowers/specs/2026-11-01-marks-layer-design.md` (part 1 of 3).

## Global Constraints

- Old scene files need not open; built-in scenes are rebuilt (standing project rule).
- Golden logs of existing scenes stay identical: `Log.marks` and the canvas never enter the log hash, and nothing in part 1 touches physics.
- Grid: cells start at 4 world px and double until the grid has at most 300,000 cells; tiles are 32×32 cells; a cell is 8 bytes `rgb: [u8; 3], amount: u8, wet: u8, team: u8, depth: u8, flags: u8`.
- Stamping uses fixed-point 16.16 integer maths for positions and radii.
- Textures: size × detail, long side capped at 4096.
- Texture checkpoints share the flow budget `CHECKPOINT_BYTES` (256 MB).
- Speed: canvas step under 1 ms for a full portrait screen (1080×1920) with 20 painting balls, release build.
- WGSL: never name a field `target`, `active` or `move` (reserved).
- Settings belong to the part that uses them. Part 1 has no dry time, spread, drips, refill, pickup, Scrape, Claim, numbers or pictures.

## Review Focus

1. **A canvas that rides a spinning obstacle:** marks must stay stuck to it. Stored in canvas-local coordinates and drawn with the canvas's current pose (Task 4 and Task 6 tests).
2. **Seek backwards past many marks, then play:** the picture must equal a straight run. The texture checkpoint restore is where this breaks (Task 6 GPU test).
3. **Balls that leave the canvas area or spawn mid-run:** no marks off the canvas, no streak from the spawn point or from position 0,0 (Task 4 test).
4. **Very fast balls (thousands of px/s):** strokes must be continuous capsules, not dots (Task 3 and Task 4 tests).
5. **A canvas with no brushes, or brushes with no canvas:** nothing breaks and nothing is logged (Task 4 test).

### Task 4: The Canvas thing and its sim

**Files:**
- Modify: `crates/bpe-kit/src/things/canvas/mod.rs` (kind + settings)
- Create: `crates/bpe-kit/src/things/canvas/sim.rs`
- Modify: `crates/bpe-kit/src/lib.rs` (register kind and sim)

**Interfaces:**
- Consumes: `CanvasGrid` (Task 2); `MarksBrushes`, `ball_colour_in_sim`, `World.looks` (Task 3); `Mark`, `Log::push_mark` (Task 1).
- Produces `CanvasSettings` (derive `Settings`), kind id `"canvas"`, name "Canvas", icon "canvas", no slots, not stuck to screen. Fields:
  - `kind: CanvasKind { Paint }`, a one-variant choice now; parts 2 and 3 add more.
  - `fit: Fit { Arena, View, Custom }`, default Arena.
  - `size: Vec2`, used when Custom; default 1080×1920.
  - `layer: CanvasLayerPos { BehindEverything, BehindBalls, OnTop }`, default BehindBalls.
  - `brushes_from: Target`, default Anything.
  - `starts_as: StartsAs { Empty, Colour }`, default Empty; plus `start_colour: Color`.
  - `style: CanvasStyle { Flat }`.
  - `detail: f32`, range 0.25 to 1, default 1.
  - `fade: f32`, range 0 to 60 s; 0 means Never; default 0.
  - `blend: Blend`, default Normal; `opacity: f32`, range 0 to 1, default 1.
- `affects_physics` is false for `layer`, `style`, `detail`, `fade`, `blend`, `opacity` and `start_colour`. It is true for the rest, since they change which marks exist.
- `CanvasSim`: `needs_walls() -> true`. `build` resolves the area: Arena means the first arena wall's bounding box, View means `world.video`, Custom means `size`. It writes the pose and stores `CanvasState { grid: CanvasGrid, size: Vec2, last: BTreeMap<(ThingId, u32), (Vec2, f32 /*load left*/)>, every: u64 }`. `scripted` updates the pose from `world.anchor(id)` the way `ObstacleSim::place` does.
- `pub fn canvas_area(world: &World, canvas: ThingId) -> Option<(Pose, Vec2)>` for the draw part.
- `after_step`, for brush things in tree order: each thing with a Marks module whose settings say `paint_on` or `splat_on`, matched against `brushes_from` with `world.matches(canvas, thing, &target)`.
  - **Paint:** every `every = (sps / 60).max(1)` steps, and for each living item that passes `paint_when`, stamp and log a Stroke from its last logged point to its current one. Points are converted to canvas-local with the inverse pose. A new item, or one whose last point is missing, starts there without a stroke. Width is in px from `paint_width_by`. `paint_load` counts down by stroke length and refills when the item's `hits` grows. A segment with both ends outside the canvas is skipped.
  - **Splat:** for each `Hit` event in `log.since(world.step)` where this thing is the mover (`a.thing`) or is hit (`b.thing`), with `speed >= splat_min_speed`, stamp at `point`.
    - Radius is `splat_size × (1 + splat_by_speed × (speed / 1000).min(2))`.
    - Angle comes from the normal for FaceHit, or a hash of (step, item) for Random.
    - Variant is that hash modulo `splat_variants`.
    - Colour is the mover's colour.
  - Mark colours come from `ball_colour_in_sim`, or from `colour_at` on Own paint. The grid cell gets the colour converted to sRGB u8, with amount 255.

**Files:**

**Interfaces:**
- Produces:
  - `pub enum CanvasPlace { BehindEverything, BehindBalls, OnTop }`
  - `pub struct CanvasLayer { pub thing: ThingId, pub center: [f32; 2], pub angle: f32, pub size: [f32; 2], pub texels: [u32; 2], pub place: CanvasPlace, pub start: Option<[f32; 4]>, pub fade: f32, pub blend: Blend, pub opacity: f32, pub time: f32 }` (`texels` = size × detail, long side ≤ 4096)
  - `pub struct CanvasTextures { pub paint: wgpu::Texture /*Rgba16Float: colour × amount, amount*/, pub aux: wgpu::Texture /*Rgba16Float: r = time painted*/ }` with `CanvasTextures::new(device, texels)`
  - `Renderer::canvas_textures(&self, thing) -> Option<&CanvasTextures>`, looked up from the flow layers (Task 6). With none, the composite draws only `start`.
- The composite draws a world quad (centre, angle, size through the camera globals) sampling both textures.
  - Flat: colour = paint.rgb / max(paint.a, ε); alpha = paint.a × fade term × opacity.
  - Fade term: `fade == 0 → 1`, else `clamp(1 - (time - aux.r) / fade, 0, 1)`.
  - A `start` colour shows under the marks.
  - Blend uses the existing blend-layer path when it is not Normal or Add.
- Draw order: BehindEverything right after the background pass; BehindBalls after walls and soft bodies, before liquids and balls; OnTop after everything in the scene pass, before text.

### Task 6: Replaying marks on the graphics card, with checkpoints

**Files:**
- Create: `crates/bpe-gfx/src/canvas/stamp.rs`, `crates/bpe-gfx/src/shaders/canvas_stamp.wgsl`
- Modify: `crates/bpe-gfx/src/flow/mod.rs` (`Layer::Canvas`, step, snapshot, prepare)

**Interfaces:**
- Consumes: `Log::marks_between`, `Log::trim_marks_upto` (Task 1); `CanvasLayer`, `CanvasTextures` (Task 5).
- `Layer::Canvas(CanvasGpu)`, where `CanvasGpu { textures: CanvasTextures, size: [f32; 2], texels: [u32; 2] }`.
  - `prepare` treats `frame.canvases` as wanted layers.
  - The "same" check compares `thing`, `size` and `texels`; a change restarts.
- Layer stepping gets the marks for its canvas from `driver.log.marks_between(prev_world_step, driver.world.step)` per flow step. Change `Layer::step` to take a small context struct holding the inputs, offset, sdf and that slice.
- `trim_log` also trims marks up to the last drawn world step.
- Stamping is one render pass per step into both textures, as instanced quads in mark order. Blending gives the GPU's in-order per-pixel guarantee, which keeps it deterministic.
  - paint: premultiplied over.
  - aux: replace where covered (`discard` outside the shape), writing `r = mark time`.
  - Shapes are signed-distance functions in WGSL, with a soft one-texel edge:
    - Stroke is a capsule, round or square tip.
    - Splat is a blob of 7 lobes perturbed by `variant`.
    - Ring is an annulus at 0.7 to 1 of the radius.
    - Star has 5 points.
    - Crack is 5 jagged rays from `variant`.
    - Burst is 12 thin rays.
    - Dots is 6 discs from `variant`.
- `Snapshot` gains `textures: Vec<wgpu::Texture>`, copied with `copy_texture_to_texture`. `Checkpoint::bytes` counts them.
