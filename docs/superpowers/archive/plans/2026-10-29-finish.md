# Finish (Stage 8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `ball-studio-next` a complete replacement for the old editor: randomize with locks on any setting, the seed explorer, batch rendering, saved presets in the Library, starter scenes, and the integration gaps the stage 3–7 reports left for this stage.

**Architecture:** The schema already marks every setting the dice may pick (`Flags::random`); stage 8 adds a dice range per setting and a `locks` set on the scene, then one kit function rolls a scene (or a thing, card or module) deterministically from a seed, honouring locks. A kit scorer rates a run from the runtime's `World` and `Log`; the CLI batch module drives prescreen → render → pick with a resumable manifest; the studio adds the windows (Randomize, Explore, Batch, Start) and the Library's "My presets" heading on top of those crates. Old crates stay untouched; the new editor keeps its `ball-studio-next` name in the repo.

**Tech Stack:** Rust 2024 workspace, egui/eframe 0.37 + egui_kittest, wgpu 30, RON, ffmpeg.

**Spec:** `docs/superpowers/specs/2026-10-29-modular-studio-design.md` (§4.4 Library and presets, §4.8 windows, §7 stage 8, §8 testing), plus the stage reports in `/mnt/project-files/ballphysics/modular-revamp/stage{3..7}/REPORT.md`.

## Global Constraints

- Old crates (`bpe-scene`, `bpe-sim`, `bpe-render`, `bpe-audio`, `bpe-export`, `bpe-app`, `bpe-music`) are not modified. The new editor stays `ball-studio-next`; the exe copy into the user's bin folder happens outside this plan and only with the user's approval.
- `BTreeMap`/`BTreeSet` everywhere, never hash maps, so saves and rolls are deterministic.
- Golden logs (`crates/bpe-kit/tests/golden*.txt`) stay byte-identical: nothing in this plan changes a simulation. New starter scenes, if any, add lines only.
- Every new control carries an accessible label (`labelled_by` or a `WidgetInfo`) so kittest can find it; no emoji glyphs (paint icons).
- Copy is plain English for a non-technical user ("Lock when randomizing", "Roll", "Use this"), no jargon in labels or hover help.
- Scene files stay backward compatible: new scene fields use `#[serde(default)]` and skip when empty.
- `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace` pass before the PR.

## Review Focus

1. A rolled value must never leave its setting's range or its dice range, and locked, keyed and `Target`/`Text` settings must never move (Task 3 tests over every scene in `scenes::all()`).
2. A scene saved by an older build (no `locks` field) must load, and a scene with locks must round-trip through RON (Task 1).
3. Rolling with the same seed twice from the same base must give the same scene, and locking one setting must not change what the other settings roll to (Task 3).
4. A batch stopped mid-way must carry on from its manifest without re-rendering finished videos, and a folder holding a batch with different settings must be refused, not overwritten (Task 5).
5. The explorer, batch and start windows must work without a graphics device (headless tests) and must not freeze the editor: thumbnails and scores are optional and scoring runs on threads (Tasks 8, 9, 10).

- [ ] **Step 3: Implement `roll_value` and `palette`**

Rules (amount `a` clamped 0..=1, `(lo, hi) = def.dice_range()`):
- `Number`/`Int`: skip without a range. Pick uniform in `[lo, hi]`, in log space when `lo > 0 && hi / lo >= 20`. Partial: `new = cur + (pick - cur) * a` in that space; clamp to `[lo, hi]`; `Int` rounds.
- `Bool`: flip when `dice.unit() < a * 0.5`.
- `Choice`: when `dice.unit() < a`, pick uniformly from `def.choices` (find the kind's choice list through `ValueType::Choice(..)`); else unchanged.
- `Color`: `a >= 1` → `palette(dice, 1)[0]` keeping alpha; else shift hue by `(dice.unit() * 2 - 1) * a * 0.5` turns, keep saturation/value.
- `Colors`: `a >= 1` → `palette(dice, len)`; else each colour hue-shifted as above.
- `Vec2`: with a range: magnitude log-uniform in `[lo, hi]`, angle uniform; partial: interpolate magnitude in log space and angle along the shorter arc by `a`. Without a range: scale magnitude by `2^((unit*2-1)*a)` and rotate by `(unit*2-1)*a*π`.
- `Target`/`Text`: `None`. Not `flags.random`: `None`.
